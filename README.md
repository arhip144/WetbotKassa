# 🤖 Что такое WetbotKassa? ✨

Это **открытый исходный код** 🔓, который вы можете использовать для запуска своего собственного бота и сервера для приема пожертвований (донатов) прямо на своем компьютере.

---

## 🎯 Зачем это нужно?

Этот проект позволяет вам настроить **автоматическую выдачу валюты и предметов** в боте WETBOT на **ВАШЕМ** сервере Discord.

### Как это работает:
*   ⚙️ Вы создаете и настраиваете своего бота.
*   💳 Игроки на вашем сервере используют команду `/donate`.
*   🤖 Ваш бот создает ссылку на оплату.
*   💰 **Вы получаете деньги напрямую себе**, а бот автоматически выдает покупку!

> **Сервер** необходим для безопасного приема уведомлений от платежной системы об успешных оплатах.

## ⚠️ Важная информация

Чтобы принимать платежи на банковскую карту, вам необходимо зарегистрироваться в **ЮKassa**.

> **ЮKassa** (ранее — Яндекс.Касса) — это популярный сервис онлайн-платежей для предпринимателей, юридических лиц и самозанятых.

### Требования для регистрации:
*   🇷🇺 Гражданство РФ
*   🎂 Возраст **не менее 14 лет**
*   📝 Статус **самозанятого**

> 💡 Если у вас еще нет статуса самозанятого, его можно оформить буквально в **пару кликов** через приложение «Госуслуги» или мобильное приложение вашего банка. 🚀

# 🚀 Пошаговая инструкция по настройке WetbotKassa

## 🔐 1. Регистрация в платежной системе
1. **Зарегистрируйте аккаунт в YooKassa** и создайте магазин  
   🌐 [https://yookassa.ru](https://yookassa.ru)

## 🤖 2. Создание Discord бота
2. **Создайте приложение Discord**  
   🎮 [https://discord.com/developers/applications](https://discord.com/developers/applications) → `New Application`

3. Перейдите в раздел **"Bot"** созданного приложения

4. ⚙️ **Настройки бота:**
   - Выключите `Public bot` 👥
   - Включите `Server Members Intent` ✅

5. Перейдите в раздел **"OAuth2"** → **"OAuth2 URL Generator"**
   - Отметьте галочку `bot` 🤖
   - Скопируйте сгенерированную ссылку и пригласите бота на свой сервер

## ⚡ 3. Установка и настройка окружения
6. **Установите Node.js**  
   📦 [https://nodejs.org/en](https://nodejs.org/en)

7. **Скачайте репозиторий**  
   ⬇️ [https://github.com/arhip144/WetbotKassa.git](https://github.com/arhip144/WetbotKassa.git)  
   (Зеленая кнопка `Code` → `Download ZIP`)

8. **Распакуйте ZIP-архив** 📂

9. **Откройте консоль** и выполните:
   ```bash
   cd <путь к распакованной папке>
   npm install
   ```
   *Ждите завершения загрузки файлов* ⏳

## ⚙️ 4. Конфигурация бота
10. **Откройте файл `botconfig.js`** любым текстовым редактором

11. **Заполните настройки:**
    - `serverId` → ID вашего Discord сервера 🆔
    - `websiteName` → название вашего сервера (без спецсимволов)  
      *💡 Если есть белый IP - оставьте поле пустым*
    - `email` → ваш E-mail для получения чеков 📧
    - `shopId` → ID вашего магазина YooKassa 🏪

12. **Настройка для белого IP** (если есть):
    - `hasWhiteIp`: `false` → `true`
    - Укажите пути к файлам сертификатов:
      - `key` → путь к файлу ключа сертификата
      - `sert` → путь к файлу сертификата  
      - `ca` → путь к CA сертификату

13. **Настройка вознаграждений:**
    - `currencyPerRuble` → количество валюты за 1 рубль  
      *💡 Установите `0` если не хотите выдавать валюту*
    - `giveItems`: `false` → `true` (если хотите выдавать предметы)
    - `items` → добавьте предметы для выдачи за донат 🎁

## 🔑 5. Настройка ключей доступа
14. **Откройте файл `.env`**

15. **Заполните секретные ключи:**
    - `discordToken` → токен вашего бота Discord  
      *📋 Можно получить в разделе "Bot" → кнопка "Reset Token"*
    - `yooKassaPrivateKey` → приватный ключ YooKassa  
      *🔐 Интеграция → Ключи API*
    - `wetbotApiKey` → ключ API WETBOT  
      *⚡ Получить командой `/manager-settings` → `API`*

## 🌐 6. Настройка уведомлений
16. **Если у вас белый IP:**
    - В настройках магазина YooKassa:  
      **Интеграция** → **HTTP-уведомления**  
      - URL для уведомлений: `https://ВАШ_IP/donate`

17. **Если белого IP нет:**
    - Запустите `start.bat` ▶️
    - Скопируйте **"Ваш URL"** из консоли
    - Вставьте в URL для уведомлений: `ВАШ_URL/donate`  
      *Пример: `https://aboba.local.lt/donate`*

18. **Настройте типы уведомлений:**
    - Включите только `payment.succeeded` ✅
    - Нажмите **"Сохранить"** 💾

## ✅ 7. Тестирование
19. **Протестируйте работу:**
    - В Discord вызовите команду `/donate` (/донат) 💸
    - Введите сумму для оплаты
    - После успешной оплаты бот автоматически выдаст награды! 🎉
